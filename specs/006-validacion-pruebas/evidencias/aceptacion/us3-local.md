# US3: hallazgos y revalidación local

Fecha: 2026-10-11. Fixtures sintéticas temporales; no hallazgos ciudadanos ni recepción real.

Pruebas de rúbricas C3/C4 y mayor severidad, tipos REAL, revisión individual Crítica/Alta, origen/caso/modelo/entorno, historial y reapertura. Validada/Cerrada exige matriz completa posterior al ajuste, caso aprobado y ambos modelos C3 o corrida funcional C4 pertinente. Un run interrumpido, un solo modelo o release distinta impide el cierre.

El dispatcher fue probado con una corrida integrada sintética de 39 resultados: finding-register comprueba el run de origen y rechaza un caso inexistente; finding-transition conserva la versión anterior, genera vista Markdown y agrega evento al ledger. Resultados locales sin inferencia usan evaluatedModel:null. Comandos y pruebas en quickstart.md; negativos/positivos pasan en test:validation.

T040 conserva pendiente la clasificación/revisión/importación de resultados reales: no se inventan causas, responsables ni aprobación de severidad.
