# Evidencias SPEC008

Un archivo por pista (`NV-01.md` … `NV-12.md`) con este formato:

- **Pista**: id y resumen.
- **Clasificación REAL** (constitución IX): Fallo de Datos / de Recuperación / de Modelo / de Seguridad-Operación.
- **Prueba antes**: comando y resultado (falla o «no reproduce»).
- **Corrección**: archivos tocados.
- **Prueba después**: comando y resultado.
- **Estado**: corregida | no explotable (con evidencia) | pendiente (bloqueo documentado).
